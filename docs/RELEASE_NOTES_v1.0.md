# RatanaOS v1.0 Release Candidate

## Highlights
- **Ratana System Manager:** New init daemon and system management core replacing legacy scripts.
- **Ratana Desktop:** Upgraded UI with modern animations, comprehensive theming engine, and Dark Mode default (Ratana-Dark).
- **Control Center & App Ecosystem:** Brand new Control Center, Installer Wizard, and Update Manager built with Qt6.
- **Advanced Kernel Integration:** Ships with hardware optimizations out-of-the-box (WiFi, BT, ASPM power management).
- **Robust Security:** AppArmor profiles implemented by default for core services.

## Known Issues
- Network setup during installation on some Broadcom chips may require manual firmware loading.
- System Monitor currently displays mock data for CPU temperatures.
