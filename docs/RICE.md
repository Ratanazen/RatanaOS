# RatanaOS Desktop Rice Specifications

## 1. Visual Identity
- **Design Language**: Modern, Minimal, Frosted Glass, Rounded Corners, Soft Drop Shadows.
- **Brand Emblem**: **THE JIRAIYA** shield logo featured in the bootloader, Plymouth boot animation, and application launchers.
- **Typography Stack**:
  - Coding & Shell: `JetBrains Mono Nerd Font` / `Fira Code`
  - User Interface: `Inter` / `Cantarell`
  - Localization: `Noto Sans Khmer` (`fonts-khmeros`)
  - Icons: `Font Awesome` + `Papirus-Dark`

---

## 2. Components
- **Top Bar / Status**: `Waybar` with modular layouts (`config-top.json`, `config-glass.json`, `config-cyber.json`).
- **Application Launcher**: `Wofi` and `Rofi` with rounded frosted card containers.
- **Notifications**: `SwayNC` with Do-Not-Disturb and quick toggles.
- **Terminal**: `Kitty` & `Foot` with `Starship` prompt and `neofetch` branding.
