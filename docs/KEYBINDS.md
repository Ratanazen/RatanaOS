# RiOS — Universal Keybindings Reference

RiOS provides a unified keyboard shortcut map across Hyprland, Niri, and Sway.

| Shortcut | Action | Scope |
| :--- | :--- | :--- |
| `Super + Space` | Spotlight Application Launcher (Wofi / Rofi) | Global |
| `Super + Enter` | Terminal Emulator (Kitty / Foot) | Global |
| `Super + Q` | Close / Kill Active Window | Global |
| `Super + E` | Open File Manager (Thunar) | Global |
| `Super + B` | Open Web Browser (Firefox) | Global |
| `Super + C` | Open Calculator | Global |
| `Super + F` | Toggle Fullscreen | Global |
| `Super + V` | Toggle Floating Window | Global |
| `Super + Escape`| Power Menu (Lock, Suspend, Reboot, Shutdown)| Global |
| `Super + L` | Lock Screen (Hyprlock / Swaylock) | Global |
| `Super + N` | Toggle SwayNC Notification & Control Center | Global |
| `Super + 1..0` | Switch to Workspace 1 to 10 | Global |
| `Super + Shift + 1..0` | Move Window to Workspace 1 to 10 | Global |
| `Print` | Fullscreen Screenshot | Global |
| `Super + Shift + S` / `Super + Shift + 4` | Area Selection Screenshot | Global |
| `Super + Shift + R` | Start / Stop Screen Recording | Global |
| `Super + ~` (Grave) | Toggle Dropdown Scratchpad Terminal | Hyprland |
| `Mod + Left / Right` | Scroll Column Ribbon | Niri |
| `Mod + R` | Switch Preset Column Width (33% / 50% / 66% / 100%) | Niri |
