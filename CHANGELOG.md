# RatanaOS Changelog

## v1.0.0 (Cyber Edition)
- **New Feature**: Introduced `ratana-cyber` and `ratana-developer` build profiles.
- **New Feature**: Added Package Selection screen to the Installer for optional cybersecurity toolkits.
- **Enhancement**: ISO builder dynamically injects compiler toolchains (GCC, Rust, Go) and security tools based on the profile.
- **Enhancement**: Added QEMU testing scripts for BIOS/UEFI boot verification.
- **Enhancement**: Integrated ISO size validation into the release checks.
