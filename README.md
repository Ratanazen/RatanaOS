# RatanaOS Cyber Edition

RatanaOS Cyber Edition is a specialized, Debian-based Linux distribution engineered for cybersecurity professionals, software developers, and system administrators. 

## Editions
- **Cyber**: Full penetration testing and development suite.
- **Developer**: Compilers, runtimes, and container tools.
- **Workstation**: Standard daily-driver with KDE Plasma.
- **Lite**: Minimal footprint for older hardware.

## Quick Start
To build the OS ISO:
```bash
./builder/build-iso.sh ratana-cyber
```

See the `docs/` folder for complete manuals!
