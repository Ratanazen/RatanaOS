# RiOS 1.0.0 Release Notes

Welcome to the first stable release of RiOS.
This release finalizes our pivot from cosmetic macOS themes to a robust, professional environment geared toward developers, sysadmins, and cybersecurity professionals.

- Debian 12 Bookworm base
- Hybrid Live ISO + Installable OS
- Desktops: GNOME, KDE Plasma, Hyprland, Sway
- Profiles: Cybersecurity, Developer, Server
